Усталяванне

Праз рэпазітар (рэкамендуецца — аўтаабнаўленні)

  1. У Kodi: Налады → Сістэма → Дадаткі → уключыце Невядомыя крыніцы
  2. Спампуйце repository.kinakipa.zip са старонкі рэлізаў
  3. Налады → Дадаткі → Усталяваць з zip-файла → абярыце repository.kinakipa.zip
  4. Усталяваць з рэпазітара → Кінакіпа Repository → Відэададаткі → Кінакіпа → Усталяваць

Наўпрост з ZIP (без аўтаабнаўленняў)

Спампуйце plugin.video.kinakipa.zip са старонкі рэлізаў і ўсталюйце праз Дадаткі → Усталяваць з zip-файла.

Для HLS-прайгравання рэкамендуецца ўсталяваны inputstream.adaptive (звычайна ідзе разам з Kodi). Калі яго няма, плагін аўтаматычна пераключыцца на MP4.
