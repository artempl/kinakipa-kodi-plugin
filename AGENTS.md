# AGENTS.md — kinakipa-kodi

Kodi video add-on for [kinakipa.site](https://kinakipa.site/) — Belarusian-dubbed
movies, TV series and cartoons. This file documents the site's (undocumented) web
API and the add-on's architecture so future work does not have to rediscover them.

## Site API (discovered 2026-11)

Base: `https://kinakipa.site`. The site is an ASP.NET app behind Cloudflare; send a
desktop browser `User-Agent` (the add-on does). HTML uses numeric character
references — always `html.unescape()`.

### Catalog listing (HTML scrape)

```
GET /Catalog?query=&type=movie|tv|&genre=&country=&minYear=&maxYear=
              &studio=&subdub=&sorting=&pageSize=50&pageNumber=1
```

- `pageSize` accepts at least 100.
- Cards: `<a href="/movie?id=326" title="...">` followed by
  `<img class="poster" src="...">` and `<div class="catalog-item__title">Title 1994</div>`.
  Episode badges ("s1e4 (субцітры)") appear on a second line of the title div.
- Pagination: an `<a class="button pagination__next" href="...pageNumber=N">` element
  exists only when there is a next page.

### Filter option lists (HTML scrape)

`/Catalog` contains `<select id="genre">`, `<select id="country">`,
`<select id="sorting">`. Parsed once and cached for 3 days in the add-on profile.

### Homepage sections (HTML scrape)

Sections are marked by `<div class="last-episodes-day__title"[ id=...]><span>Title</span>`
followed by poster cards. Observed: «Глядзяць зараз», «Актуальныя рэлізы»,
«Новыя эпізоды», «Фільмы і серыялы 2026 года», «Экранізацыя коміксаў»,
«Выпадковыя тайтлы», plus non-catalog blocks («Кампаніі», «Доступ па падпісцы»).
Titles rotate, so the add-on resolves sections by title and falls back to a list.

### Item page (HTML scrape)

`GET /movie?id={kinopoisk_id}` — metadata lives in:

| Data | Selector |
|---|---|
| type | `data-cinemaplayer-query-api-type` (`movie` / `tv`) |
| title + year | `<h2 class="about-serial-header__title">«Title» 1997-2026</h2>` |
| original title | `about-serial-header__subtitle` — `Title / Original (1994) / міні-плэер` |
| poster | `.about-serial-poster img[src]` |
| fanart | `.bg-cover-bg img[src]` (1280-ish still) |
| plot | `<meta name="description" content="...">` |
| genres/countries/directors/cast | `ul.about-serial-characteristics li` → `span.font-light-16` label + `span.font-light-18` value |
| KP rating | label `KP`, value `9.2 (499100)` |
| premium flag | page contains `прэміум кантэнту` |

### Playable sources (JSON)

```
GET /api/user/player/information?id=77044
```

```json
{"simple-api": [
  {"id": "2087486519", "name": "Агучка",
   "iframe": "https://iframe.mediadelivery.net/embed/142530/<guid>?autoplay=false&ffec=00:22:40",
   "episode": 1, "season": 1}
]}
```

- `season`/`episode` are absent for movies; present for series.
- `name` ends with a provider code: `BX` = Bunny Stream, `A` = AniBel,
  `V` = VK video, `GX` = Google Drive (`... Player BX`, `Субцітры A`, …).
- Only Bunny Stream is playable by the add-on. VK/Google Drive/AniBel sources are
  hidden unless the user enables «Паказваць крыніцы VK / Google Drive».

### Stream resolution (Bunny Stream)

Bunny embed pages expose the HLS playlist directly (no token):

```
GET https://iframe.mediadelivery.net/embed/{library}/{guid}
  → https://vz-{hash}.b-cdn.net/{guid}/playlist.m3u8
```

The CDN host depends on the library (`142530`, `129236`, `142818`, …), so always
parse it from the embed HTML. Progressive fallbacks live next to it:
`https://vz-{hash}.b-cdn.net/{guid}/play_{240,360,480,720}p.mp4` (probe with HEAD;
1080p is not always rendered). `playlist.m3u8` resolves 240p–1080p. Variant URIs are directories such as
`1920x1080/video.m3u8` (or `720p/video.m3u8` in older libraries), so parse
`RESOLUTION=` and `urljoin` the next line — never construct the path by hand.
The `Якасць HLS` setting pins one rendition by handing its media playlist to
IA, which keeps the quality fixed instead of adapting.

### Other endpoints

| Endpoint | Result |
|---|---|
| `GET /api/user/movie?query=kevin` | JSON autocomplete: up to 5 items with full metadata, `id`, `poster`, `player` (comma-joined episode list) |
| `GET /api/public/random` | `302` → `/movie?id=N` (used by «Выпадковы тайтл») |
| `/player?id=N` | mini player page (the add-on does not need it) |
| `/embed?id=N&hash=0` | one-line iframe wrapper (not needed) |

## Add-on architecture (`main.py`)

Single file, stdlib only, Kodi 19+ / Python 3. Sections in order:

1. Settings helpers (`_setting`, `_page_size`, `_mp4_quality`, `_playback_mode`)
2. HTTP layer — `http_get`, `http_location`, `http_json`, `http_exists`, `SiteError`
3. Disk cache in the add-on profile (`cache.json`) — resolved playlists, MP4
   renditions, filter lists
4. Favourites store (`favorites.json` in the profile, `toggle_favorite`, context menus)
5. HTML helpers + parsers (`parse_cards`, `parse_home_sections`, `parse_item_page`,
   `parse_select`, `fetch_sources`)
6. Stream resolution (`resolve_stream`, `_bunny_playlist`, `_pin_quality`, `_bunny_mp4`)
7. Views (one function per `action`) and the `VIEWS` router

Router actions:

| `action` | Params | View |
|---|---|---|
| `root` (default) | — | main menu |
| `search` | — | keyboard → redirects to `catalog` |
| `sections` / `sec` | `n` (section title) | homepage sections |
| `catalog` | `query`, `type`, `genre`, `country`, `minYear`, `maxYear`, `sorting`, `page`, `title` | poster grid |
| `sorting` | catalog params | sorting menu |
| `genres` / `countries` / `years` | — | filter menus |
| `item` | `id`, optional `season` | sources / seasons / episodes |
| `play` | `u` (iframe URL), `t` (title), `p` (poster) | resolves + `setResolvedUrl` |
| `favorites` | — | saved titles from `favorites.json` |
| `fav_toggle` | `id`, `t`, `p`, `y` | add/remove favourite + `Container.Refresh` |
| `random` / `settings` | — | redirect / `openSettings` |

Kodi facts used: `sys.argv[0]` = plugin URL, `sys.argv[1]` = handle,
`sys.argv[2]` = `?query`. HLS playback needs
`li.setProperty('inputstream', 'inputstream.adaptive')` and
`inputstream.adaptive.manifest_type = hls`. `inputstream.adaptive` is declared
`optional="true"` so the add-on installs without it.

## Testing

`tests/kodi_stub/` implements the small surface of `xbmc`, `xbmcgui`,
`xbmcplugin`, `xbmcaddon`, `xbmcvfs` that the add-on touches.
`tests/harness.py` runs `main.py` with `runpy.run_path(..., run_name='__main__')`
and a synthetic `sys.argv`, capturing directory items, notifications and the
resolved URL.

```bash
python3 tests/test_live.py     # hits the real site, ~40 assertions
```

Tests run against live content; IDs used (326, 77044, 10250911, 3498, 161252) are
stable enough but update them if the site drops a title. The harness forces
`playback_mode=2` (MP4) to keep runs fast, then explicitly checks both modes.

## Build & release

```bash
./scripts/build.sh            # uses versions from addon.xml
./scripts/build.sh 1.1.0      # bumps plugin version first
```

This regenerates `pages/addons.xml` + md5 and both repo-style zips
(`pages/{id}/{id}-{version}.zip`, which Kodi's repository protocol expects).
Commit `pages/` and push to `main`; `.github/workflows/pages.yml` deploys it.

Manual release zip for the Releases page:

```bash
cd plugin.video.kinakipa && zip -r ../releases/plugin.video.kinakipa-$(grep -oP 'version="\K[^"]+' addon.xml).zip .
```

## Gotchas

- Cloudflare blocks plain `Python-urllib` UAs — keep the browser UA setting.
- Card titles include the year; strip it with a trailing `(19|20)\d{2}` regex and
  keep ranges (`1997-2026`) intact.
- `html.unescape` is mandatory: the site's HTML is numeric-entity encoded.
- Bunny CDN hosts differ per library — never hardcode `vz-...` hosts.
- The add-on's `_url()` takes an optional `_params` dict because catalog params
  dicts already contain `action`.
